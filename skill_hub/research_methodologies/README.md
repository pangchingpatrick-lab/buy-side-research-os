# Research Methodologies

`skill_hub/research_methodologies/` stores reusable thinking patterns distilled from high-quality researchers.

These files should not summarize a researcher's opinions, copy their content, or treat their public views as facts. They should extract the reasoning pattern: how a researcher finds signals, frames questions, maps companies, translates evidence into financial impact, builds variant views, and defines invalidation.

## Role In The Skill Hub

The Skill Hub separates five layers:

- Thinking skills define reusable reasoning actions.
- Research methodologies define how to reason.
- Industry frameworks define what to inspect.
- Analysis methods define how to validate.
- Report templates define how to communicate.

Research methodologies sit before industry frameworks. They define the reasoning path before the system decides what industry-specific map to inspect:

```text
Classified research packet
-> thinking skill router: which reasoning actions to combine
-> research methodology: how to reason through the question
-> industry framework: what matters in this industry
-> analysis methods: how to validate the claim
-> report template: how to communicate to a PM
```

## What Belongs Here

- reusable reasoning workflows
- signal-to-thesis patterns
- company mapping logic
- financial translation logic
- variant view logic
- risk and invalidation logic
- output style guidance

## What Does Not Belong Here

- copied posts, articles, or transcripts
- summaries of a researcher's current opinions
- unsupported investment conclusions
- fabricated data, URLs, accounts, or metrics
- raw X signals or unclassified source dumps

## How To Use

1. Start from a classified research packet.
2. Select one or more research methodologies that fit the research question and signal type.
3. Use the selected methodology to define the reasoning path.
4. Use `skill_hub/router.md` to select the relevant industry framework after the reasoning path is clear.
5. Use `skill_hub/analysis_methods/` to validate the claims.
6. Use `skill_hub/report_templates/` to communicate the final output.

## Current Methodologies

- `serenity.md`: a signal-driven buy-side reasoning workflow that emphasizes what changed, value-chain mapping, financial translation, variant perception, and invalidation.
- `research_event_distillation.md`: an event-level methodology for turning public claims into auditable signal logic, evidence stacks, price-in questions, report-use decisions, and memory candidates.
- `methodology_evaluator.md`: a rubric for comparing reports generated by different methodologies.
