# Valuation Method

Use this method to test whether a thesis is already priced in.

## Inputs

- current price and market cap
- revenue, EPS, EBITDA, FCF estimates
- peer multiples
- historical multiples
- DCF assumptions if available
- broker consensus and target prices

## Steps

1. Select the relevant valuation lens: multiple, DCF, sum-of-the-parts, or expectation gap.
2. Compare current valuation with peers and history.
3. Test whether consensus estimates already include the thesis.
4. Identify upside/downside drivers.
5. Define what would trigger rerating or derating.

## Output

| Company | Valuation lens | Current expectation | Variant assumption | Upside/downside driver | Data gap |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

## Guardrails

- Do not fabricate multiples or estimates.
- If market data is unavailable, mark `待补充`.
- Tie valuation to the earnings mechanism, not just narrative strength.
