# Event Validated Patterns

This file stores evaluated patterns about which research events tend to be useful.

It is not raw data and should not be updated from a single unevaluated post. Add a pattern only after a report or event audit has been evaluated.

## Starter Patterns

### Multi-evidence Stack Beats Single Viral Signal

Event clusters are higher quality when they combine:

- customer signal
- supply-chain constraint
- earnings / guidance / order evidence
- specialist or primary-source confirmation

Do not promote a viral post to high confidence without evidence stack support.

### Focal Beneficiary Beats Context Ticker

A ticker should drive a company thesis only when it is the focal beneficiary, supplier of the scarce layer, or explicit risk object.

Customer, peer, comparison, and background tickers are useful for mapping but weak as direct investment signals.

### Scarce-Layer Discovery Is Stronger Than Theme Repetition

The strongest early signals usually identify:

```text
new demand driver
-> newly stressed system layer
-> scarce capability
-> under-discussed beneficiary
-> evidence that can be verified
```

Broad theme repetition should be treated as context unless it adds new evidence.

### Early And Confirming Signals Need Different Use

`early_discovery` can create research priority.

`continuation_confirmation` can support conviction.

`late_validation` can explain current consensus but should not be described as alpha discovery.

### Price-In Question Is Part Of Evidence Quality

For public equities, the same claim has different value depending on whether it appeared before or after market recognition.

If market-reaction data is missing, the correct output is a validation task, not a confident conclusion.
