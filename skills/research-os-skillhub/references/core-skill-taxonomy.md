# Core Skill Taxonomy

Core skills define the dominant thinking mode before frameworks or templates are selected.

Canonical files live in:

```text
skill_hub/core_skills/
```

## Skill 001: Baimaonv Distillation

Use for:

- strong public research cases
- hidden upstream assets
- overlooked chokepoints
- alpha migration
- market label vs actual economic role

Output influence:

- case logic
- narrative discipline
- blind-spot detection
- absorb useful Skill 005 reference patterns into existing thinking skills when a case demonstrates demand shock, constrained layer, scarce capability, or event reasoning

## Skill 002: SemiAnalysis Distillation

Use for:

- AI infrastructure
- semiconductors
- GPU clusters
- HBM
- networking
- ASICs
- foundry
- advanced packaging
- datacenter capex
- CPO / optical interconnect

Output influence:

- technical bottlenecks
- supply-demand logic
- infrastructure economics
- AI-infrastructure bottleneck method: workload / architecture transition -> stressed layer -> scarce capability -> supplier exposure

## Skill 003: Equity Research Playbook

Use for:

- earnings, guidance, KPIs, management commentary
- single-name investment memo
- platform thesis
- moat, pricing power, market share
- PM-facing equity research

Output influence:

- company thesis
- financial path
- valuation and PM action state
- cross-industry bottleneck-to-beneficiary logic inside equity research: constrained layer -> company role -> earnings impact -> price-in question

## Skill 004: Serenity Bottleneck Mapping

Use for:

- finding scarce layers
- ranking value-chain layers before companies
- "who benefits from X"
- hidden upstream constraints
- company proximity to bottleneck

Output influence:

- constraint map
- direct and indirect beneficiary map
- alpha migration
- uses `ai_infrastructure_bottleneck_method.md` and `cross_industry_bottleneck_framework.md` as shared method backbone

## Skill 005: Research Event Distillation

Use for:

- X, a16z, GeoScope, newsletter, blog, or public-claim audit
- claim/evidence/ticker-role separation
- discovery-stage classification
- price-in question
- duplicate thesis clustering

Output influence:

- event ledger
- source discipline
- report-use decision for early signals
- event-level reasoning through ticker role, evidence stack, discovery stage, price-in status, and duplicate thesis clustering

When Skill 005 is selected, usually also route to:

- `skill_hub/thinking_skills/skill_009_research_event_reasoning.md`
- `skill_hub/research_methodologies/research_event_distillation.md`

When the public event is about a bottleneck or beneficiary map, also route to:

- `skill_hub/thinking_skills/skill_010_cross_industry_bottleneck_event_mapping.md`

Skill 005 does not replace Skill 001-4. It adds event-level discipline and contributes shared reference frameworks that 001-4 can absorb during case distillation, technical reasoning, equity mapping, and scarce-layer mapping.

## Selection Rule

Use Skill 005 as primary for signal audit.

Use Skill 003 as primary for PM-facing company reports.

Use Skill 004 as primary for scarce-layer and theme-to-beneficiary reports.

Use Skill 002 as primary when the technical architecture is the central problem.
