## Evaluation

Every full report should be scored for:

- route discipline
- thinking dominance
- local data discipline
- noise filtering
- industry framework use
- PM-grade core conclusion
- Signal-to-Alpha logic
- mapping quality
- financial validation
- consensus / variant view
- investment judgment
- validation loop
- event audit discipline

## Memory Rule

Memory is not raw data.

Do not update memory from one interesting source item.

Only update memory after:

```text
report generated
-> report evaluated
-> reusable lesson identified
-> memory update candidate created
```

## Memory Candidate Should Include

- source report
- route used
- evaluator score
- reusable pattern or failure mode
- whether the lesson is general or industry-specific
- how future routing should change
