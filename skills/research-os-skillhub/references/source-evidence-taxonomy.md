# Source Evidence Taxonomy

Use this reference to grade source quality.

Canonical detail file:

```text
skill_hub/references/source_evidence_taxonomy.md
```

## Evidence Strength

### Strong

- filing
- earnings transcript
- investor presentation
- official company statement
- regulatory document
- contract or order disclosure
- audited or structured database

### Medium

- specialist research
- broker note
- trade publication
- reputable news
- cross-source confirmation

### Weak

- X post
- screenshot
- public thread
- unverified channel check
- price action alone
- rumor
- short opinion

## Verification Status

- `verified`
- `partially_verified`
- `unverified`
- `contradicted`
- `data_missing`

## Report Rule

Strong evidence can support conclusions.

Medium evidence can support hypotheses with caveats.

Weak evidence can create leads or validation tasks.
