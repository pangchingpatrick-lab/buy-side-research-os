# Calling Sequence

This is the mature-skill calling order for the Research OS SkillHub.

```text
user question
-> skills/research-os-skillhub/SKILL.md
-> runtime data layer
-> context packet
-> skill_hub/registry.md
-> skill_hub/router.md
-> route.md / route.json
-> selected references
-> selected core skill
-> selected thinking skills / methodology
-> selected industry frameworks
-> selected analysis methods
-> selected report template
-> report
-> evaluator
-> validation tasks
-> memory update candidate
```

## Layer Roles

- Runtime data layer: stores prepared evidence.
- Registry: lists available modules.
- Router: selects the route for one task.
- References: explain labels, fields, roles, and standards.
- Core skills: decide the dominant thinking mode.
- Thinking skills / methodologies: shape reasoning.
- Industry frameworks: support inspection.
- Analysis methods: validate the reasoning.
- Report templates: control output.
- Evaluator: score quality and find hard failures.
- Memory: store evaluated lessons only.

## Anti-Pattern

Do not go directly from raw data to report.

Always route first.
