# Research Packet Template

Use this template when converting runtime `system_index` records into a temporary context packet.

A context packet is the standard bridge between the runtime data layer and the Skill Hub router. It organizes early signals, verified evidence, company mapping, credibility, gaps, and analysis questions so `skill_hub/router.md` can choose the right thinking skills, methodologies, industry frameworks, analysis methods, and report templates.

The packet must not contain final investment conclusions. It may include an initial hypothesis, but it should not decide `long`, `short`, `act`, or produce a final PM recommendation.
